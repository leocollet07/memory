# Memory

🎮 Jeu de Memory réalisé en JavaScript.

## Démo

[Accéder au jeu](https://leocollet07.github.io/memory/)

## Technologies

- HTML5
- CSS3 et CSS Grid
- JavaScript ES6
- API Picsum

## Fonctionnalités

- 16 cartes et 8 paires d'images
- Mélange
- Détection des paires
- Chronomètre et compteur de coups
- Réinitialisation de la partie

## Lancement local

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/leocollet07/memory.git
   ```

2. Ouvrir le dossier dans VS Code.
3. Lancer `index.html` avec Live Server.
